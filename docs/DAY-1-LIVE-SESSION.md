# ⚡ Day 1 Live Synchronous Session: The Sovereign Onboarding Protocol

## ⏱️ Session Timeline & Blueprint

### 1. 00:00 - 00:20 | The LMS Autopsy (The Manipulative Tool Audit)
* **Action:** Project the university's official LMS admin dashboard directly onto the screen.
* **The Provocation:** Show students the invisible background student usage tracking charts that log exactly what time an individual clicks a file, how many seconds they hover over a reading, and the automated corporate risk scores the algorithm silently assigns.
* **The Framework Hook:** Introduce **Audrey Watters'** critique alongside **Ivan Illich’s** definition of a **Manipulative Tool**. Explain that this course intentionally secedes from commercial LMS infrastructure because we refuse to subject students to data enclosure, surveillance capitalism, or Skinnerian behavioral nudging. 

### 2. 00:20 - 00:45 | The Infrastructure Secession (Building the Convivial Web)
* **Action:** Students open their pre-configured workspace tools based on their available hardware.
* **Execution Path Alpha (Desktop / Laptop):** Walk the class step-by-step through initializing a decentralized local sandbox via their native terminal or Git Bash:
  
  ```bash
  mkdir -p impacts-of-computing && cd impacts-of-computing
  git init

- **Execution Path Beta (Mobile Only):** Walk mobile users through opening the official **GitHub App** (or **Working Copy** on iOS), locating their repository profile, and selecting the local initialization/workspace branch layout.
- **The Framework Hook:** Connect this physical act to **Minimal Computing** and Illich’s concept of a **Convivial Tool**. Explain that running this initialization builds an autonomous data vault under their own control. By bypassing bloated corporate trackers, both desktop and mobile users are actively constructing a localized, privacy-preserving piece of a peer-to-peer **Learning Web**.

### 3. 00:45 - 01:15 | The Intellection Thought Experiment (The Second Watershed)

- **Action:** Project a highly complex, optimized AI-generated response text or a piece of synthetic imagery on the board.
- **The Debate:** Challenge the room with a core question: *This software is displaying highly optimized, complex output behavior. Is it thinking?*
- **The Framework Hook:** Introduce Illich's law of **The Second Watershed** alongside the Vatican document ***Antiqua et nova\*** (§14). Break down the fundamental distinction between:
  - **Ratio:** Discursive, rule-bound, step-by-step optimization (the exclusive domain of neural networks and large language models).
  - **Intellectus:** Intuitive, embodied, relational understanding rooted in human conscience.
- **The Warning:** Warn the room that when optimization tools cross the Second Watershed, they stop serving human utility and begin enclosing human intellect. Define their semester goal: protecting *intellectus* from being flattened into an opaque corporate data monopoly.

### 4. 01:15 - 01:30 | Initializing the Pseudonymous Covenant

- **Action:** Walk students through generating their Git identification keys or mobile configuration handles, keeping their personal student usage data detached from global commercial analytics.
- **Deliverable:** Instruct them to clone/fork the main upstream repository and open their first asynchronous Pull Request, Issue ticket, or mobile file edit to register their terminal handle to the course network—formally establishing their independent, sovereign workspace.
